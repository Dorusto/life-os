# Timeline

The Timeline tab shows the complete history for the selected vehicle, organized by month. It's the place to review past entries, spot reminders, and delete any entry you no longer need.

## Header and vehicle switcher

At the top of the page you'll see the page title and a dropdown to switch between vehicles. Choose a different vehicle to see its own timeline.

## Reminders banner

If there are any upcoming reminders for the selected vehicle, a banner appears above the list. It shows a short message about the reminder and includes a link to the Reminders tab. The banner disappears when there are no reminders.

## Month grouping

Entries are grouped by month, with the newest month at the top. Each group has a month label (for example, "September 2026") and the entries for that month appear below it.

## Entry row

Each entry row shows:

- An icon that indicates the entry type (for example, fuel, service, or other).
- The type label (for example, "Fuel", "Service", "Other").
- The cost of the entry.
- The date and odometer reading at the time of the entry.
- For fuel entries, a line with the litres, price per litre, and location.
- For other entries, a line with any notes you added.

## Delete button

Each entry has a delete button. Clicking it removes the entry from the log. After deletion, the timeline refreshes to show the updated list.

## Empty state and add-entry form

If there are no entries for the selected vehicle, you'll see a message telling you the timeline is empty. Below the list (or in place of it) there's a form to add a new entry. Fill in the details and submit to add the entry to the timeline.
