# Holdings

The Holdings screen lists every position in your portfolio, showing cost basis, market value, and unrealized gain.

## Summary tiles

At the top of the page you see four summary tiles:

- **Market value** – the total current value of all open positions.
- **Cost basis** – the total amount you have invested, using the average-cost method.
- **Unrealized gain** – the difference between market value and cost basis, shown as a currency amount and a percentage.
- **Open positions** – the number of positions currently open.

These tiles give you a quick snapshot of your portfolio's performance.

## Include closed

The **Include closed** checkbox lets you toggle whether closed positions are shown in the table. When it is off (the default), only open positions appear. When you turn it on, the table also includes positions you have fully sold, and the gain/loss column for those rows shows the realized gain instead of unrealized.

## Table columns

The table has the following columns:

- **Security** – the ticker symbol, an asset-type pill (e.g., stock, ETF, crypto), and the security name.
- **Shares** – the number of shares you hold.
- **Average cost** – the average purchase price per share, using the average-cost method.
- **Price** – the current market price per share.
- **Value** – the current market value of the position (shares × price).
- **Weight** – the percentage of your total portfolio value that this position represents.
- **Gain/Loss** – the unrealized gain or loss for open positions, shown as a currency amount and a percentage. For closed positions (when "Include closed" is on), this column shows the realized gain or loss instead.

## Gain/Loss cell

For open positions, the gain/loss cell shows the difference between the current value and the cost basis, both as a currency amount and as a percentage. For closed positions, it shows the realized gain or loss from the sale.

## Footnote

The footnote below the table explains that:

- Cost basis uses the **average-cost method** and is a tracking figure, not a tax figure.
- For securities not denominated in EUR, the price and value are shown in the security's native currency.

## Empty state

If you have no positions, the page shows an empty state with a link to add your first holding.
