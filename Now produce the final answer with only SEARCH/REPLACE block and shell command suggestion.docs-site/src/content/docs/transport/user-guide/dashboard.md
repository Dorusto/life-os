# Dashboard

The Dashboard is the at-a-glance summary for the selected vehicle. It shows key metrics and upcoming reminders.

## Vehicle switcher

At the top of the page you can select which vehicle you want to view. The choice carries across all tabs, so when you switch vehicles here, the other pages (like trips or service) will show data for the same vehicle.

## View vehicle details

There is a link labeled **View vehicle details →** that takes you to the full details page for the currently selected vehicle.

## Fuel economy

The Fuel economy card shows:

- **Average L/100km** – the average fuel consumption over the vehicle's history.
- **Last fill L/100km** – the consumption measured at the most recent fill-up.
- **Last price per litre** – the price you paid at the last fill, along with the date of that fill.

## Costs

The Costs card shows three totals:

- **This month** – total costs for the current calendar month.
- **This year** – total costs for the current calendar year.
- **All time** – total costs since the vehicle was added.

## Distance

The Distance card shows:

- **Odometer** – the current odometer reading.
- **This month** – distance driven in the current month.
- **This year** – distance driven in the current year.

## Reminders

The Reminders section lists the next two upcoming reminders. Each reminder shows:

- The reminder name.
- The due date or due odometer reading.
- A horizon text that tells you how far away the due date or odometer is. If a reminder is overdue, the text will indicate that.

There is also a **View all** link that takes you to the full list of reminders.

## Empty state

If there are no vehicles in your account, the Dashboard shows a message telling you that you need to add a vehicle first.

## Error state

If the summary fails to load, the Dashboard shows an error message. You can try refreshing the page or check your connection.
