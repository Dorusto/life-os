### Lessons
- **The first backend task through the pipeline exposed that the overlay never worked.** `docker compose build majordom-api` failed on a root-only file in `data/`, and `run.py` ignored the exit code, so gates and the visual check tested the old container and produced a false FAIL. Fixed in the pipeline (build/up/health failures are fatal) and at the source (`.dockerignore`).
- **`Dockerfile.backend` does `COPY . .`.** Without `.dockerignore`, the image on the LXC carried `.env`, `data/` and gitignored private notes. The next deploy rebuild drops them.
- **The private-data scanner's credential regex has false positives** on `x = _func()` and `os.environ.get(...)` values (it exempts only `os.getenv(`). Worked around both times; the regex itself is unchanged.
- **Twelve Data cannot serve this portfolio on the free plan.** `.DE`/`.US` suffixes are invalid symbols, and XETRA ETFs require the Grow plan. Findings are posted on #292; the source choice belongs to #42.
