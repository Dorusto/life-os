## 2026-09-23 (late) — #303 diagnosed live on the LXC: root cause is an upstream actualpy bug, not Majordom's code

### Resolved
- **#303 root cause found and confirmed, not guessed.** Read-only investigation against real LXC
  data (`scripts/ab_audit.py`, plus a direct read-only call to `Actual.bank_sync_transactions()`)
  found `ING current` was missing 53 real transactions (a full week, Sept 1-6, entirely absent).
  Root cause: every `run_bank_sync()` call for this account throws `pydantic.ValidationError` on
  Enable Banking's `XPCD` balance-type code, which `actualpy`'s `BalanceType` enum doesn't
  recognize — silently swallowed by `run_bank_resync_all()`'s per-account `try/except`, so sync
  "runs" with no visible error but imports nothing. Confirmed upstream and unfixed even in the
  latest release (0.22.3): [bvanelli/actualpy#208](https://github.com/bvanelli/actualpy/issues/208).
  Decision: track upstream, don't build a local workaround now (see `docs/decisions.md#303-actualpy-enable-banking-incompatible`
  for the full reasoning) — the user's own bank-sync button in Actual Budget's native UI works as
  a fallback (different code path, native sync). After the user ran it, `ING current`'s AB-vs-real
  gap dropped from ~€1982 to ~€96.50.
- **The remaining ~€96.50 gap fully explained:** one manual-vs-synced duplicate (`Tankstelle
  M.Weber` €96.50 vs. `SHELL 2508` €96.50, same day) — the app's own existing duplicate-review
  machinery (`#181`/`#229`) correctly found it, but it was buried in 132 false positives.
- **Fixed the false-positive source:** `_find_duplicate_candidates()` had no date window at all
  (an explicitly-flagged, accepted trade-off from #229 — "revisit only if this turns out noisy in
  practice"). Added a 7-day window, same convention already used by `ab_audit.py`'s `dupes()`.
  Reduced 134 candidates → the 2 real ones on live data. Commit `63521dc`.
- **#306 filed** (not fixed): Connections page guesses the wrong port (`${origin}:5006`) on this
  Tailscale-`serve` deployment, where the correct port is different (found live while the user was
  trying to reach the Actual Budget UI directly — unrelated to #303's cause).

### Files modified
