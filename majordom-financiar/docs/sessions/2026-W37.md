### Lessons
- **Uncommitted work from a prior session is not "done" just because it was built and Docker-rebuilt** — no session log or issue meant the duplication debt it introduced went unreviewed for 8 days. Running `pre-commit-review` on it (even though every line had already been read manually) is what caught the violation; the skill's "skip only when already reviewed" bar was met on paper, but running it anyway here was the right call given the code's unclear provenance.
- **A three-way copy is not always visible from one diff alone.** The 2026-09-03 diff only *added* the second copy of the dispatch (vehicle_proposals.py); the first copy (confirm_receipt, confirm_fuel_receipt already duplicating it inside receipts.py) predated it and was never itself flagged. Worth checking for existing near-identical control flow in the *same file* being touched, not just the diff's own new code.
