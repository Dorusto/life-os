# 2026 — Week 38

## 2026-09-14 — Overnight mass-delegation session: cross-app bug sweep + docs generation

### Resolved

- **Meta-delegation pattern established and used for real.** Doru sent an extensive cross-app bug/feature list (two large messages, ~40 screenshots total) across all three apps — Majordom Finance, Majordom Transport (`tools/vehicle-manager`), Majordom Invest (`tools/investment-manager`) — with an explicit instruction to delegate as much as possible to DeepSeek (Flash for code, the text-only variant for prose) and minimize Claude's own token usage, including the task-authoring step itself for large batches. New pattern: one Aider run generates a batch of task specs delimited by `===TASK-BREAK===`, split via `awk`, then dispatched as one isolated git worktree + branch per spec. Used both for the bug-fix batch and for a 35-page documentation-site scaffold (Astro/Starlight, `docs-site/`). Full narrative in `~/.claude/skills/delegate-by-complexity/references/decisions.md`'s 2026-09-14 entry.

- **Dispatch tooling had a false-positive reporting bug, found and fixed twice.** The first dispatch script (`dispatch_batch.py`) trusted Aider's own exit code and reported "35/35 docs done" — untrue. Root cause #1: exit code alone doesn't mean a real diff landed. Fixed by verifying an actual `git log --name-only` diff plus real file content (not a placeholder, ≥200 bytes) — v2. Still under-delivered on a retry batch. Root cause #2, deeper: the script launched Aider from a nested app directory with `../` relative paths, which silently broke Aider's own `git add` under `--subtree-only` worktrees. Fixed by launching from the worktree root — v3. Also found and handled a **corrupted-filename bug**: Aider occasionally leaked its own reasoning text into a SEARCH/REPLACE file-path header, creating a garbage-named tracked file — detected via `git log --name-only` scanning for abnormally long/sentence-like paths, cleaned up via `git rm`. Final real count: 32/35 doc pages generated automatically and verified by content, the remaining 3 written directly by hand after two rounds of OOM kills on the automated retry, at Doru's explicit direction once further automated retries stopped being worth it — genuine 35/35.

- **Zombie-process finding.** One Aider subprocess from the very first (pre-fix) dispatch run survived an earlier `pkill` and was still running 9h50m later, competing for memory with the fresh v3 retries and contributing to the OOM kills. Killed directly (`kill -9`), confirmed gone. `dispatch_batch.py`/`retry_specs.py` now wrap the subprocess call in an explicit `timeout=600` so this class of leak can't recur silently.

- **Three real cross-app deployment-wiring bugs found only via live browser verification** (not caught by `tsc`/build alone): the Finance→Transport vehicle-account redirect, and the shared "open Majordom chat" button in both Transport and Invest, were correctly implemented in code but gated on `VITE_*` env vars that were never actually plumbed through to the frontend build — Vite bakes `VITE_*` vars in at build time, which needs both an `ARG`/`ENV` pair in the Dockerfile *and* a matching `args:` block in `docker-compose.yml`; only the first half existed. Fixed: `ARG`/`ENV VITE_VEHICLE_APP_URL` added to `majordom-financiar/frontend/Dockerfile`; `ARG`/`ENV VITE_MAJORDOM_FINANCE_URL`/`VITE_INVESTMENT_MANAGER_URL` added to `tools/vehicle-manager/frontend/Dockerfile`; `ARG`/`ENV VITE_MAJORDOM_FINANCE_URL` added to `tools/investment-manager/frontend/Dockerfile`; build `args:` blocks added to all three services in `docker-compose.yml`, wired to three new `.env` variables (`WEB_PUBLIC_URL`, `VEHICLE_APP_PUBLIC_URL`, `INVESTMENT_MANAGER_PUBLIC_URL`, documented in `.env.example`). Live-verified in browser: vehicle-linked account now hands off to Transport's detail page, the shared chat button opens Finance's `/chat` from both other apps.

- **Several smaller UI bugs fixed** across the three apps per Doru's screenshot list — bottom bar styling on the Finance Dashboard, hardcoded dark-mode colors (`BudgetRebalanceCard.tsx`/`AccountTransferCard.tsx`, `#1A1A1A` → `var(--surface-2)`), widget remove-button visibility, notification popup clipping, 3-column widget grid, a new vehicle-costs summary widget, shared Settings-gear and notification-bell components across all three apps, Transport's vehicle-selector styling, moving inline reminders (Timeline + Home) onto the shared bell, an inline purchase-price entry point on Transport's "unavailable" warning, a new Transport Settings page, and 5 new Analytics sections on Finance (Trends Comparison / Cash Flow / Net Worth History / Net Worth Drivers / Investment Projection) for MoneyMatter-reference parity.
