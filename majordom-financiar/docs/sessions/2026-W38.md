### Lessons

- `check-private-data.sh` only pattern-matches structured data (plates/IBAN/VIN/Telegram IDs/domain/IPs) — real names and personal locations need a human read, not a regex; a generic "real name" or "real place" detector isn't feasible without constant false positives (this repo's docs legitimately say "the user" and "Netherlands"/"Dutch" throughout). Worth remembering to explicitly ask for a private-data pass (not just correctness) whenever reviewing an agent's unsupervised multi-file batch, rather than assuming the pre-commit scanner covers it.
- A container with broken push access is, accidentally, a safety net — the 44-commit batch's two leaks never reached GitHub only because push had been broken since before the batch was written. Don't take that as a reason to leave push access broken on purpose; it just means the same review should happen even when push works fine.
