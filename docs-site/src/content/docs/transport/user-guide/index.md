The Transport app is a small set of tabs plus a detail page. This section walks through each screen.

| Screen | Description | Page |
|---|---|---|
| Dashboard | Overview of the current vehicle's key metrics. | [Dashboard](/transport/user-guide/dashboard) |
| Vehicles | List of all vehicles and access to vehicle details. | [Vehicles](/transport/user-guide/vehicles) |
| Vehicle detail | Detailed information about a single vehicle. | [Vehicle detail](/transport/user-guide/vehicle-detail) |
| Timeline | Chronological events for the selected vehicle. | [Timeline](/transport/user-guide/timeline) |
| Stats | Statistics and charts for the selected vehicle. | [Stats](/transport/user-guide/stats) |
| Reminders | Upcoming maintenance or other reminders. | [Reminders](/transport/user-guide/reminders) |
| Import | Import data from external sources. | [Import](/transport/user-guide/import) |

Navigation is simple: a bottom tab bar lets you switch between the main tabs. Most tabs have a vehicle switcher at the top, so you can quickly change which vehicle you're viewing. The vehicle detail page and the import screen are reached from the Vehicles tab.

Every tab is scoped to the currently selected vehicle, so the data you see always relates to the vehicle you've chosen.
