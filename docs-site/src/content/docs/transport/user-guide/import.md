title: Import Fuelio CSV
description: Learn how to import a Fuelio sync CSV to create a vehicle in the app.
---

The only way to add a vehicle to the app is by importing a Fuelio sync CSV.

## What is a Fuelio sync CSV?

You can export your vehicle data as a CSV file from Fuelio's settings. This file contains your vehicle's name, fuel entries, and cost entries.

## Import screen

On the **Import Fuelio** screen, you'll see a file picker and an **Import** button.

Click the file picker to select a Fuelio sync CSV file from your device.

The **Import** button becomes active once you've selected a file.

While the import is running, the button shows **Importing…** and is disabled.

If the import fails, you'll see an error message on the screen. The error message explains what went wrong, so you can fix the file and try again.

## Result card

After a successful import, you'll see a result card with the following information:

- **Vehicle name** – the name of the vehicle that was created or updated.
- **Fuel entries imported** – how many fuel entries were added.
- **Fuel entries skipped** – how many fuel entries were skipped (for example, because they were duplicates).
- **Cost entries imported** – how many cost entries were added.
- **Cost entries skipped** – how many cost entries were skipped.

At the bottom of the card, there's a **Back to vehicles** button that takes you to your vehicle list.

## Importing the same file again

If you import the same CSV file again, the app updates the existing vehicle instead of creating a duplicate. This is useful if you've added new entries in Fuelio since your last import.

Remember, importing a Fuelio sync CSV is the only way to create a vehicle in this app.
